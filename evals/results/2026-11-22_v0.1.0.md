## Failures found and fixed during the runs

| Found in | Problem | Fix |
|---|---|---|
| S5 (M4) | The catch-up showed 2 recent log lines, because a dedupe rule dropped one | Template: always show the last 3 |
| S3 run 1 (M5) | Sessions invented times hours apart | `get_now`: a NOW() clock cell in the sheet; every timestamp comes from it |
| S3 run 1 | A bare "approve" was refused while several jobs had pending gates | Job-in-focus rule |
| S3 run 1 | Replies listed other jobs and repeated the job card at every gate | Short gate replies |
| S7 run 1 (M7) | Changing an approved decision was flagged as a contradiction | Conflict rules: that's a `change_request` |
| Live (M7) | Sample data had stages marked done without their outputs | Data fixed; the validator now checks it |
| S9 (M8) | Files mode lost log entries beyond the last 20 | `jobs/<id>/log-full.json`, append-only |
| S11 (M8) | Two exports wrote empty list cells differently (`[]` vs left out) | Storage rule: an empty cell means the field is left out |
| S9b (M8) | After feedback was saved, `next_action` still named the old step | client-feedback asks producer to refresh `next_action` |
