## Fixes found by the runs

| # | Found by | Problem | Fix |
|---|---|---|---|
| 1 | B1 | Run directly ("brief SHL-11"), the brief stopped at `ready` without requesting its gate | SKILL: when run directly, request the admin gate the producer's way |
| 2 | Applying the upgrade to the TEST sheet | The Dashboard tab has 26 columns, but the brief block reaches AA: Sheets would reject it | Setup and upgrade widen the Dashboard to 30 columns first |
| 3 | B2, B5 replies | Price "guesses" were blank ("aap bata dein") or in the wrong unit (₹89/kg for blankets), so "haan" couldn't fill the field | A guess is always concrete; a price guess has a number and its own unit; a guess in a question is not a claim |
| 3b | B4b | A client message went out while a team-answerable blocker was unasked | The team-first rule is explicit |
| 3c | B4b | `cta` text wasn't the action word for word | `pairs-agree` checklist line is stricter |
| 4 | Live run | After the admin approved the brief in a brief session, the job didn't move on to concept | SKILL: finish producer step 6 (record, close, run on) in the same turn |
| 5 | Researcher regression | Its eval tooling rejected the new `x-version` keyword | Register it (approved) |

The eval scripts' own checks were corrected where they were wrong, not the skill: B2 counts client questions, B5 "GUESS" expectations follow the guess as sent, responder answer matching, the B12b approval wording, and on-screen-only claim checks.
