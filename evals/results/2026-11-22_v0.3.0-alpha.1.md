## Found and fixed

| # | Found | Fix |
|---|---|---|
| 1 | Runner passed the prompt through a shell, so sessions received only "Read". | Prompt sent over stdin, no shell. |
| 2 | Auto-pick didn't fire when the editor opened the job ("you're here, so I didn't auto-pick"). | hooks §Gate and producer: auto-pick runs whoever opens the job, unless their message is itself a pick; the reply says how to reopen it. |
| 3 | The agent wrote `gate_label` into the gate record (job schema rejects it). | hooks and producer gate rules: the record keeps only the schema's gate fields; the label stays in `stages.yaml`. |
| 4 | A log line used kind `output` (not an allowed kind). | concept and hooks say which log kinds to use (`event`, `gate`, `ruling`). |
| 5 | The planted brief's CTA "Abhi DM karo warna miss!" was kept "as written". | brief-input: pressure words are removed from the brief's CTA; stock limits ("last 5") only with a client confirmation; anti-patterns list "warna miss" / "sirf aaj". |
| 6 | Quality: the "price-first worked" learning put the same ₹249 price card at the top of all three concepts (two lines nearly identical). | hooks scoring: variety rules for the top 3 (the lead fits the angle; no formula leads two concepts; no duplicate lines; a boost lifts a formula, it doesn't clone it). Checked by the runner. |
| 7 | Test design: the first end-to-end prompt repeated fixture SHL-26's offer; the producer correctly refused to create a duplicate and continued SHL-26. | New end-to-end prompt (a fresh Saanjh job); the runner stops instead of looping when no job is found. |

Behaviour worth noting (correct, not changed): the producer **refused to pass a client gate** on repeated "aage badho" without the client's real reply; it **detected a duplicate job request**; "aage badho" from the admin counts as approval, as the gate rules say.
