# Knowledge

Shared know-how used by **3 or more skills**: platform specs (aspect ratios, safe zones, length limits), Indian festival calendar, Hindi/Hinglish writing rules, and similar.

Rule: if only one or two skills need it, it lives in that skill's `references/` folder instead. Move it here when a third skill needs it.

Skills link to files here as `${CLAUDE_PLUGIN_ROOT}/library/knowledge/<file>.md`.
