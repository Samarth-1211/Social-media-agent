# Before showing: concept self-check

Run on every save. Record each line in `concept.data.self_check.items` (`id`, `ok`, `note`). `passed` is true only if every line passes; fix and re-check once, then save with the failing lines noted.

| Id | Check | Pass when |
|---|---|---|
| CC1 | **Three different angles** | `concepts_count` concepts, each a different `angle_type`, and they differ on at least two of audience slice, format, lever, hook tactic. |
| CC2 | **Insight, sourced** | The core insight and each concept's insight have a `source`; any `assumption` is listed in `assumptions`. |
| CC3 | **No invented proof** | Every price, date, count, review, year and customer is from the brief, profile or research, or shown as `{{needed: …}}`. |
| CC4 | **Brief delivered** | Each concept lands the key message, uses the real offer and CTA (pressure words removed, `brief-input.md`), gives `mandatories` a beat, and breaks nothing in `avoid` / `dont` / `never_use`. |
| CC5 | **Distinct** | No concept rests on a `competitors_overdo` item or a psychology §4 cliché unless it visibly flips it. |
| CC6 | **Producible** | Each concept has shots by source, difficulty and credit band; the recommended one fits the job budget and deadline. |
| CC7 | **Real stays real** | Real customers, results and places are real footage; AI shots are never presented as real; renders of unbuilt things are marked to be labelled. |
| CC8 | **Language** | Lines follow the brief's `language` and `writing_script`; natural spoken Hinglish, nothing "too pure" or translated. |
| CC9 | **Timing** | Story beats add up to `duration_sec`; the hook beat is the first 2–3 s. |
| CC10 | **Levers honest** | 1–2 levers per concept, each with proof, none used in its misuse form (psychology §5). |
