# Hook anti-patterns

What kills retention or trust. Each has a name (used in `critique_note`) and a fix. The first group loses attention; the second loses trust and is never allowed in the top 3.

## Kills attention

| Name | Looks like | Fix |
|---|---|---|
| **slow** | Greeting, intro, "aaj hum baat karenge", the hook buried in sentence three | Delete the first sentence(s); start where the interesting word is. |
| **brand-first** | Logo, shop name or "We are excited to announce" in the first 2 s | Lead with the viewer's pain, outcome or the visual; the brand comes in the payoff. |
| **vague** | "Life easy banao", "best service", "you won't believe" | Name the category of the answer, a concrete noun, a real fact. |
| **single-layer** | A good line over a static face with no text | Design the visual and text too (`three-layers.md`). |
| **needs-explaining** | Wordplay, an in-joke, a reference to decode | Clarity first; save wit for the payoff. |
| **three-act** | The hook has its own setup and only lands at second 8 | One beat. If it needs setup, the setup is the hook. |
| **broad** | "Indore walon", "sab log" | Narrow to a situation or an area ("Bhawarkua ke hostel walon"). |
| **generic** | Would work for any business in the niche | Put in what only this client can say: their place, phrase, process, price. |
| **too-pure** | Textbook Hindi, translated English (`language-rules.md`) | Rewrite as spoken Hinglish. |
| **cringe** | "Namaste dosto", "5 amazing tips", emoji rain, forced rhyme, "bro" off-voice, a dead trend | Cut it; say the thing plainly. |
| **lecture** | Commands and moralising ("Aapko yeh karna chahiye") | Talk with them: a situation, a question, a "galti aapki nahi". Check the client's `rejected` learnings (some owners dislike "stop doing X"). |
| **no-payoff** | Promises something the concept doesn't show, or shows only at the end | Change the hook to what the concept delivers, before the halfway mark. |

## Kills trust (never in the top 3)

| Name | Looks like | Rule |
|---|---|---|
| **invented-number** | "10,000+ customers", "98% results", a precise number nobody measured | Real numbers from the brief, profile or research, or no numbers. |
| **fake-urgency** | "Only today", "last 2 slots", a countdown with no real end date | Deadlines only from `offer_detail.validity` or a real event date. |
| **unprovable-claim** | "No.1", "best", "cheapest", "guaranteed results" | Only provable, current claims (H25 rules). |
| **fake-person** | AI or actors shown as real customers; a review that wasn't given | Real customers with consent, or a clearly staged scene that doesn't claim to be a customer. |
| **shaming** | Body, skin colour, age, weight, gender, a messy home as a joke | Show the problem without blaming a person. |
| **fear** | Health scares, "aapka ghar kharab ho jayega", disaster framing | Honest loss (what waiting really costs), never fear. |
| **put-down** | A named or recognisable competitor mocked or compared unfairly | Compare with "the usual way", never a rival. |
| **sacred-misuse** | Rituals, deities or community markers as gimmicks | Festivals as the occasion's real job, respectfully; check the client's beliefs. |
| **cringe-bait** | Built to provoke rage or mockery for shares | Never; short-term reach, long-term damage. |
| **engagement-bait** | "Comment YES", "tag 3 friends" | One real CTA from the brief. |

A hook with any trust anti-pattern gets `brand_safety` 0, is marked `replaced`, and is rewritten in the critique pass.
