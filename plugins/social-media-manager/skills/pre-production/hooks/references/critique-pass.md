# Critique pass

After scoring, per concept: take the **3 weakest hooks**, diagnose each, rewrite or replace, re-score once. This is where a batch goes from "fine" to sharp. Don't loop beyond one round.

## 1. Diagnose: name it

Read the hook aloud and time it. Then name the main problem from `anti-patterns.md`: **slow, brand-first, vague, single-layer, needs-explaining, three-act, broad, generic, too-pure, cringe, lecture, no-payoff**, or a trust anti-pattern. "This is vague" helps; "this is weak" doesn't. Write it in `critique_note`.

If the same problem shows up in several hooks, it's one habit: fix the habit across the batch.

## 2. Rewrite with the upgrade ladder

Try these in order; stop when it works:
1. **Add a real fact:** the price, the date, the area, the customer's own phrase. Never invent one.
2. **Cut the first words.** Most weak hooks bury the point.
3. **Name the exact viewer or situation** ("Bhawarkua hostel walon", "mehmaan 6 baje aa rahe hain").
4. **Make the first frame do the work:** move the stake into the visual (a before/after cut, a hand mid-action, the offer card on the real product).
5. **Add a contrast:** consensus vs truth, before vs after, ghar vs shop.
6. **Swap a flat verb** for a spoken one (bigad gaya, nikal gaya, ho gaya).
7. **Turn a statement into a withheld reveal** ("Kaise? Aakhri tak dekho"), only if the concept pays it off early.

If two or three upgrades still leave it flat, **the formula is wrong for this concept**: replace it with a different formula from `formula-catalog.md` (choosing table at the end).

## 3. Record it

- The original: `status: replaced`, `critique_note` with the diagnosis and the new id.
- The rewrite: a new id, `rewritten_from` = the original, scored again.
- A trust anti-pattern is always replaced, never "improved" in place.

## Example (fictional laundry)

| Before | Diagnosis | After |
|---|---|---|
| "Shubh Laundry presents: best quality dry cleaning in Indore!" | brand-first + unprovable-claim | H15: "\"Saree ka dry clean safe hai na?\" Roz yeh sawaal aata hai." |
| "Kya aap apne vastron ki dekhbhaal se pareshaan hain?" | too-pure + vague | H26: "Office 10 baje, aur press wala phir nahi aaya." |
| "Hurry! Offer sirf aaj tak!" (brief says 25 Nov) | fake-urgency | H18: "Diwali ke mehmaan ek hafte mein. 20% off, 25 Nov tak." |
